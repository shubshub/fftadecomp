# 080920F8 scanline blend constructor

The original Thumb body occupies 136 bytes at `080920F8..08092180`, including four literal words, and has 56 reachable instructions. The agbcc -O2 source reproduces 132 of 136 bytes and 52 of 56 instructions. At `08092138` and `0809213A` the original loads 16 into R6 and zero into R4. At `08092144` and `0809214A` it uses R4 and R6 respectively. The compiled version exchanges the two constants and their corresponding store registers. The four differing bytes implement the same pair of per-scanline stores.

The first allocation is 84 bytes. The initializer at table entry zero of `0836D4B8` clears it. The second allocation is 328 bytes. Its first 320 bytes hold 160 pairs of alpha coefficients and its byte at +324 selects the DMA record. The pair writer is also present at `08092084` and in matched `080901A8`. The two pinned BLDALPHA shadow byte assignments pass the original, stripped and layout-perturbed compiler checks.

Native execution used the original IWRAM installation routine `08002768` with BIOS CpuSet modeled, heap initialization `080227E8`, and DMA initialization `08000A48`. On separate fresh runs for channels 0, 1 and 3 the two allocations returned `020159E4` and `02015A44`. All 160 coefficient pairs and the two display-shadow bytes became (0, 16). Channels 0 and 3 registered the inner buffer as the source, BLDALPHA at `04000052` as the destination and `A2400001` as the stored control. Channel 1 was reserved by DMA initialization and its record stayed clear. The constructor returns the outer allocation with mode zero. These runs assume two successful allocations and a valid DMA channel.

The original setter `08092198` and updater `08090214` operate on this same record layout in native tests. Setting center 80 and limit 8, then updating in mode 1, advances position to 1 and writes (16, 15) on scanline 80. After `080921A8` switches to mode 2, the next update takes position and mode back to zero. No direct caller or stored pointer to this constructor has been identified.
