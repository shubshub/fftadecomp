# 0808C630 inventory ability panel

The public agbcc compiler with `-mthumb-interwork -O2` produces a 916-byte complete symbol. The USA ROM has 367 reachable Thumb instructions and 24 direct calls to 13 targets. The candidate matches the first 301 bytes, 790 of 916 byte positions, and the last 283 bytes. The remaining differences are in the ability-loop register allocation and instruction scheduling.

At `0808C75C`, immediately following the ability-name draw, the ROM begins `movs r2, #0; mov ip, r2; movs r3, #0`. The candidate begins `movs r3, #0; mov ip, r3`. The compiler also keeps the scratch graphics address in a low register across the icon decode and copy. The ROM reloads it. The ROM and candidate symbol SHA-256 digests are `67f1b1e891cd8e956bb53ea831d35595b4ef4dd795d05c2a0cadc12abe6b9337` and `4085d5f9ffd646cfd5bced49b5eca41a7f9c45189bb7a86fd850cb28a57511b8` respectively.

Eight native calls target the routine at `080780EE`, `080822F0`, `08082F5E`, `08082FB0`, `08083250`, `080832EC`, `08083330`, and `080833FE`. At `080822EE` the caller reads a halfword at offset 4 of a 20-byte inventory entry and passes it in R0. Two calls pass zero. The owner uses the incoming word for the first 32-byte item-table index, stores its low halfword in the panel, and explicitly narrows it for `080C8D14`. The candidate therefore uses a word argument. The recovered declaration in `src/08082254.c` currently uses `u16`. This declaration would need reconciliation before promotion.

The two 12-byte aggregate copies read genuine adjacent three-entry ROM tables at `081499C4` and `081499D0`. Their entries point to character VRAM for ability names and job icons. Both data symbols were registered only in the private matching fixture. A public guarded-switch verifier already models the item grant collector and its 28-byte output for `0806FABC`. That owner's admission does not cover this routine's aggregate copies, indexed local accesses or BIOS calls. The normal guarded-switch and BIOS local-fill selectors reject the ROM mismatch. The finite small-copy binding selector requires an actual canonical small-copy call and rejects these inline aggregate copies.

A differential ARMv4T run exercised all 376 physical item records with the original USA renderer, grant collector, installed IWRAM clear code and all other native callees. The harness provides a mapped inventory panel and tilemap and models the BIOS copy/fill services. Both bodies produced the same item and ability string pointers, BIOS command arguments, transferred data, panel state, tilemap and character VRAM for every record. The cases comprise 10 bypass items, 150 with zero groups, 96 with one, 82 with two and 38 with three. These observations support the reconstruction under the exercised setup. The public MATCH gate requires byte identity.
