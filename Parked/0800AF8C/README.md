# 0800AF8C

The single tested natural candidate reads a little-endian halfword from the
byte pointer at object offset 0x18. It preserves the byte loads and the incoming
pointer/result ABI; existing callers use a halfword result.

With fixed agbcc `-mthumb-interwork -O2`, the native matcher returned exit 1:
`compiled symbol is shorter than the indexed span: 12 < 30`.
The complete candidate symbol is 12 bytes; the complete indexed target is
30 bytes / 15 reachable instructions. The extent gate refused before byte
comparison and plausibility, so neither later gate is claimed.

The target additionally copies the incoming pointer to R2, loads the halfword
flags at +2 at 0x0800AF90, and computes two unused masks: `flags & 8` at
0x0800AF92..0x0800AF94 and `flags & 0x8000` at
0x0800AF96..0x0800AF9A. Both mask results are overwritten without controlling
a branch, store, call, or return. The flags value is also dead after these
operations. Natural decoding C omits that work and uses a leaf return.
No artificial dead flag operations, redundant branches, or compiler steering
were introduced. No additional candidates were tested. The unmatched active
source is removed; no native report was generated by the extent refusal.
