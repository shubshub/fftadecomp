# 080A95EC — actor filter

The fixed compiler produces the complete 196-byte Thumb symbol. GNU ld with the
six original Thumb targets produces bytes identical to the USA ROM from
080A95EC through 080A96AF. The reachable graph has 92 instructions. The linked
text SHA-256 is `cb921382ad3b25c5ef7546216cf755a9d6bafa90eecdfd832e6f1cd92da0832f`.

The original object has six R_ARM_THM_CALL relocations, at offsets 16, 22, 3C,
80, 96 and A0 hexadecimal, and no data relocations. The callback checks actor
eligibility, tests range, optionally rolls a chance, and appends accepted actors
to the caller's list. It returns one on every path.

## Output-buffer contract

The caller passes a four-byte local to the equipment collector. The ordinary
matcher follows the original calls through 0812F0D8, 0812E55C and 0812E4F4.
The collector initializes two halfwords, scans five equipment slots and appends
one halfword per qualifying entry. The caller's eligibility checks do not count
qualifying equipment. The native proof rejects the potential third output.

A separate Unicorn run called the original 0812F0D8 with a five-halfword output
array and executed its real helpers and ROM tables. It returned each count from
zero through five for the corresponding test inventories. Both array guards and
the entry SP were preserved. A two-result bound would require an independently
established restriction on the inventories reaching this caller.

The recovered source stays parked without MATCH credit.
